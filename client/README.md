# SmartHouse Frontend

React/Vite frontend for the SmartHouse project.

## Requirements

- Node.js 20+
- pnpm

## Development

```bash
pnpm install
pnpm dev
```

## Production Build

```bash
pnpm build
```

## Build Preview

```bash
pnpm preview
```

## Lint

```bash
pnpm lint
```

## Notes

- The frontend uses React Router for client-side navigation.
- In production, built assets are served by the Flask backend.
